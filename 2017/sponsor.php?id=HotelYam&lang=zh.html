塩旅社

-我們透過旅店與來自世界各地的朋友交流- 社會公民 / 你我都是這個世界的公民，透過行動關注而讓我們的社會更有活力，我們透過實際的行動參與社會，取之社會回饋社會的生態系統的建構，共存共好。 多元串連，接線生 / 讓塩旅社成為接線生，串接起各種可能與跨域整合，在這個快速的時代，不同領域的對話與串接已是不可或缺的關鍵。 在地文化 / 日本時代，因為運輸與打狗築港需求，將鹽場填海造陸，變成新市街。也將縱貫線鐵道延伸到打狗港邊。 鐵道是高雄港與鹽埕發展的重要火車頭。 YAM一方面為「塩」的台語音譯，另一方面YAM英文字意「蕃薯」，具有台灣象徵意義。
