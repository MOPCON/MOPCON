田哲禹(James Tien)

Cloud

Innovate with New Technologies on Google Cloud


講者介紹

現職 Google Cloud 台灣區經理。2012 年開始接觸雲端服務，有幸見證科技發展上的重要轉變，隨著許多企業開始利用雲端服務，加速創新，擴充商業版圖到全球各地。喜歡技術快速迭代與進步，也喜歡藝術帶來的感動，最喜歡的 APP 是 Spotify。


議程介紹

不管是 SRE (網站可靠性工程)、CRE (顧客可靠性工程)或是雲端營運等等，都是維持 Google Cloud 的運作、規模與效能的重要議題。在這場議程當中，Google 將與大家分享他們如何建構內部的流程去持續改善可靠性。我們亦將討論最佳的實作方式以減少平均偵測時間與平均恢復時間，以及如何應用 SRE 原則在你的組織當中運作。
