Brig：用愛釋放你的 UI 開發能量！


講者介紹

開放原始碼開發者，曾為 LXDE 核心開發者，也喜愛公開貢獻各種開發成果或心得於網路上。也是一個打不死的創業者，參與許多團隊與創業計畫。過去曾協助各種社群活動，並成立黑客松台灣以推廣黑客松文化，也協助企業組織推動內部創新革命和開放分享精神。


議程介紹

缺一張皮嗎？那就用 Node.js 和 Qt 打造你酷炫的跨平台應用程式吧！如今像 Tesla 這樣的新科技產品，全面採用觸控介面、打造虛擬的控制面板，其 UI 設計讓人如此神暈目眩，你可知道其 UI 就是用 Qt 技術所打造出來的呢？ 但有多少人懂 C/C++ 這樣硬梆梆的語言，又能有效率地打造出變化萬千的應用程式呢？Brig 專案帶來一個機會，讓你可以用 Node.js 來整合 Qt 的使用者介面技術！
